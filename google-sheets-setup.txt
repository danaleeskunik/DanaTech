חיבור כלי הניהול ל-Google Sheets — הוראות התקנה
=================================================

עדכון חשוב אם כבר חיברת בעבר (2026-08-13)
-------------------------------------------
כל שיעור שנוסף בכלי (תלמיד/ה חדש/ה עם מפגש שבועי קבוע, שיעור חד-פעמי, או
שינוי מועד לשיעור קיים) יתווסף עכשיו גם ל-Google Calendar שלך, עם תזכורת
שעה מראש. זה משתמש באותו סקריפט שכבר מחובר ל-Sheets, אז צריך לעדכן אותו:
1. תוספים (Extensions) ← Apps Script.
2. מחקי את כל הקוד הקיים, והדביקי מחדש את כל התוכן העדכני של
   google-sheets-sync.gs.
3. שמרי, ואז: Deploy ← Manage deployments ← עריכה (העיפרון) ← ליד
   Version בחרי New version ← Deploy.
4. בפעם הראשונה שהסקריפט ינסה לגעת ביומן שלך, ייתכן שתתבקשי לאשר הרשאה
   נוספת (חוץ מה-Sheets שכבר אישרת) — זה תקין, זה בדיוק אותו חשבון גוגל,
   ואפשר לאשר בביטחון.
האירועים נוספים ל"יומן ברירת המחדל" שלך (זה שמופיע כשפותחים
calendar.google.com עם החשבון שאיתו הותקן הסקריפט). שיעורים קבועים (עם
יום ושעה שבועיים) נוספים כאירוע חוזר; שיעור חד-פעמי או שיעור שהוזז נוסף
כאירוע בודד. ביטול חד-פעמי (לא שינוי מועד) עדיין לא מוחק את האירוע
ביומן — זו מגבלה ידועה, אפשר לבקש שיתווסף בהמשך אם נחוץ.

עדכון חשוב אם כבר חיברת בעבר (2026-08-10)
-------------------------------------------
נוסף טאב חדש "אנשי קשר" (לידים/פניות לפני שהופכים לתלמידות) — וה-Sheet
צריך לדעת עליו. אם כבר עשית את ההתקנה הזו בעבר, צריך לעדכן את הקוד הישן:
1. תוספים (Extensions) ← Apps Script.
2. מחקי את כל הקוד הקיים, והדביקי מחדש את כל התוכן העדכני של
   google-sheets-sync.gs.
3. שמרי, ואז: Deploy ← Manage deployments ← עריכה (העיפרון) ← ליד
   Version בחרי New version ← Deploy.
לשונית "אנשי קשר" תיווצר לבד בגיליון בפעם הראשונה שתשמרי איש קשר בכלי —
אין צורך ליצור אותה ידנית.

עדכון חשוב אם כבר חיברת בעבר (2026-08-03)
-------------------------------------------
נוספו לכרטיס התלמיד/ה שדות חדשים (איש קשר נוסף, איך הגיעה אליי, יום הולדת,
שיעור אחרון שלימדנו) — וה-Sheet צריך לדעת עליהם. אם כבר עשית את ההתקנה
הזו בעבר, צריך לעדכן את הקוד הישן:
1. תוספים (Extensions) ← Apps Script.
2. מחקי את כל הקוד הקיים, והדביקי מחדש את כל התוכן העדכני של
   google-sheets-sync.gs.
3. שמרי, ואז: Deploy ← Manage deployments ← עריכה (העיפרון) ← ליד
   Version בחרי New version ← Deploy.
אין צורך ליצור גיליון חדש או לחבר מחדש בכלי הניהול — זה רק עדכון לקוד
הקיים. אם עדיין לא חיברת Google Sheets בכלל, פשוט המשיכי משלב 1 למטה.

מה זה עושה
----------
כרגע הנתונים (תלמידים, תשלומים, סיכומי שיעור, אנשי קשר) נשמרים רק בדפדפן של המחשב שבו
הזנת אותם. אחרי ההתקנה הזו, הם יישמרו גם בגיליון Google Sheets משותף —
כך שתוכלי לראות ולערוך את אותם הנתונים מהמחשב ומהטלפון גם יחד.

שלב 1 — יצירת הגיליון
----------------------
1. פתחי sheets.google.com ולחצי על "גיליון חדש".
2. תני לו שם, למשל "דנה טק — נתונים".

שלב 2 — הדבקת הקוד
--------------------
1. בתפריט למעלה: תוספים (Extensions) ← Apps Script.
2. תמחקי את מה שכתוב שם, ותדביקי במקום את כל התוכן של הקובץ
   google-sheets-sync.gs (נמצא באותה תיקייה).
3. שמרי (סמל הדיסקט או Ctrl/Cmd+S).

שלב 3 — פרסום כ-Web App
-------------------------
1. למעלה מימין: Deploy ← New deployment.
2. ליד "Select type" ← בחרי Web app.
3. הגדרות:
   Execute as:        Me (החשבון שלך)
   Who has access:    Anyone
4. לחצי Deploy. אולי תתבקשי לאשר הרשאות — זה תקין, זה החשבון שלך.
5. יופיע קישור שמתחיל ב-https://script.google.com/macros/... —
   העתיקי אותו. זו כתובת ה-API שהכלי ישתמש בה.

שלב 4 — חיבור בכלי הניהול
---------------------------
1. פתחי את index.html.
2. למעלה, לחצי על הכפתור "חיבור Google Sheets".
3. הדביקי את הכתובת שהעתקת בשלב 3, ואשרי.
4. הנקודה ליד הכפתור תתחלף ל: מסתנכרן… ואז מסונכרן ל-Sheets.

חשוב לחזור על שלב 4 בכל מכשיר (מחשב, טלפון) כדי שכולם יתחברו לאותו הגיליון.

איך לדעת שזה עובד
-------------------
אחרי חיבור, פתחי את הגיליון ב-Sheets — אמורות להיווצר שם ארבע לשוניות:
תלמידות, תשלומים, סיכומי שיעור, אנשי קשר (הלשונית האחרונה נוצרת רק
בפעם הראשונה ששומרים איש קשר בכלי). כל שמירה בכלי הניהול (תלמיד/ה חדש/ה,
רישום תשלום, איש קשר חדש וכו') תעדכן את הלשונית המתאימה תוך כמה שניות.

בעיות נפוצות
-------------
- הנקודה נשארת אדומה / "שגיאת סנכרון": בדקי שהעתקת את הכתובת המלאה,
  ושב-Deploy בחרת "Anyone" ולא "Anyone with Google account".
- שינית את הקוד ב-Apps Script אחרי הפריסה הראשונה: צריך לעשות שוב
  Deploy ← Manage deployments ← עריכה (העיפרון) ← Version: New version ← Deploy.
- זה לא עובד בלי אינטרנט. זה בסדר — הכלי הזה מיועד לשימוש כשיש חיבור זמין.

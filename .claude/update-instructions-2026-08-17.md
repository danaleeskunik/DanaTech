# DanaTech — עדכון תוכנית הלימודים (גרסה 2026-08-17)

הקובץ `curriculum.json` מחליף את תוכנית הלימודים הקיימת. הוא מקור האמת היחיד:
מערך השיעור, גליון התרגול ושיעורי הבית נגזרים כולם ממנו.

## מה השתנה מהמצב הקיים

1. **ארבע רמות במקום שלוש.** רמה 2 הקודמת ("מחשב ואינטרנט") פוצלה לשתיים:
   רמה 2 — טלפון מתקדם ואינטרנט, רמה 3 — מחשב. הרמה הקודמת "מתקדם" (AI) היא רמה 4.
2. **25 מפגשים, מספור רצוף לכל רמה.** אין יותר `badge: 'שיעורים 3–4'` —
   כל מפגש הוא רשומה אחת עם `n` משלו.
3. **45 דקות למפגש, חמישה שלבים קבועים** בכל מפגש: פתיחה 5 · חזרה 7 ·
   חומר חדש 18 · תרגול מודרך 10 · סיום 5. הסכום תמיד 45.
4. **אבטחה ונגישות בהתחלה.** הגדלת טקסט במפגש 1 של רמה 1, קוד נעילה במפגש 2,
   קודי אימות והונאות במפגש 6 (במקום בסוף הרמה וברמה הבאה).
5. **שיעורי הבית הם גם גליון התרגול.** אין שתי רשימות נפרדות.
6. **`deviceSplit`** — שדה חדש: היכן שאנדרואיד ואייפון (או Windows ו-Mac) נבדלים,
   הנוסח לשניהם מופיע ברשומה עצמה.

## מבנה `curriculum.json`

```
{
  version, lessonMinutes: 45,
  phaseTemplate: [{ key, name, minutes } × 5],
  levels: [{
    level, name,
    sessions: [{
      n, title, goal,
      materials    | null,
      callout      | null   // { tone: 'tip' | 'warn', text }
      deviceSplit  | null   // { labels: [a, b], a, b }
      phases: [{ key, name, minutes, steps: [] } × 5],
      homework: [ 3 מיתרים ]
    }]
  }]
}
```

## מה לעשות בכל קובץ

הקבצים האלה הם Claude Artifact bundled pages — לפני כל עריכה קראי את
`.claude/agents/danatech-advisor.md`, סעיף "How to actually edit index.html's real
app code". אותה פרוצדורה (json.loads → עריכה → json.dumps → `.replace('</', '<\\u002F')`)
תקפה לשלושת הקבצים. אחרי כל קובץ: round-trip verify, ואז צילום מסך במובייל ובדסקטופ.

### 1. `teaching-toolkit.html`

- **להחליף את `PLANS`** בנתונים מ-`curriculum.json`. מיפוי שדות:
  `badge` ← `'מפגש ' + n` · `title` ← `title` · `dur` ← `'45 דקות'` ·
  `goal` ← `goal` · `materials` ← `materials` ·
  `tip`/`warn` ← `callout.text` לפי `callout.tone` ·
  `phases[]` ← `phases[]` (`name`, `time: minutes + ' דקות'`, `kind: key`, `steps`) ·
  `hw` ← `homework`.
  שימי לב: `kind` הקיים מכיר `open|main|practice|close` — צריך להוסיף
  `review` ל-`PH` (מפתח הצבעים). הצבע המוצע: `#0F2E52`. `drill` מחליף את `practice`.
- **להחליף את `PRACTICE`** — כל sheet נגזר ישירות ממפגש: `n` ← `n`,
  `title` ← `title`, `sub` ← `'לאחר מפגש ' + n`, `tasks` ← `homework`.
  לא לכתוב רשימת משימות נפרדת. אם אפשר — לגזור את `PRACTICE` מ-`PLANS` בקוד,
  ולא לשמור אותו כשני מקורות.
- **`LV`, `LV_BG`, `LV_NAME`** — להוסיף מפתח `4`. הצבעים:
  1 `#006EE5` / `#EAF2FD` · 2 `#00A563` / `#EAF7F1` · 3 `#0F2E52` / `#EAEEF4` ·
  4 `#E1631B` / `#FDEEE6`.
- **בורר הרמות** — כרגע `[1, 2, 3]`, להפוך ל-`[1, 2, 3, 4]`.
- **הבאג של הסימונים המשותפים.** מפתח המשימה כיום:
  `'p' + level + '-' + gi + '-' + si + '-' + ti` — בלי מזהה תלמידה, ולכן שתי
  תלמידות באותה רמה חולקות סימונים. להוסיף את מזהה התלמידה הנבחרת לתחילת
  המפתח, ולנקות את `dana_tasks_v1` בעליית גרסה (או לעבור למפתח `dana_tasks_v2`).
- **עריכת שיעורי בית.** בהצעה שנבנתה יש עריכה מקומית של שיעורי הבית לכל מפגש,
  נשמרת ב-`localStorage` תחת `dana_hw_edits_v1`, במפתח `'L' + level + '-' + n`,
  והערך הוא הרשימה המלאה המעודכנת. אם מעבירים את התכונה — לשמור על אותו מפתח,
  ולהשתמש ברשימה המעודכנת גם בהודעת הוואטסאפ וגם בהדפסה.

### 2. `practice-sheets.html`

- להחליף את `PRACTICE` באותו גזירה מ-`curriculum.json` (זהה לסעיף למעלה).
- `LV_NAME` כאן שונה מזה שב-`teaching-toolkit.html` — לאחד לשמות שב-`curriculum.json`.
- לוודא שהמספור בגליון מתייחס למפגש ("לאחר מפגש 4") ולא ל"שיעורים 3–4".

### 3. `index.html`

- **שדה `level`** — כרגע `'מתחיל' | 'בינוני' | 'מתקדם'`. להחליף לארבע הרמות של
  `curriculum.json`. המיפוי לנתונים קיימים: `מתחיל` → רמה 1, `בינוני` → רמה 2,
  `מתקדם` → רמה 4. **רמה 3 (מחשב) היא חדשה — אין תלמידות שממופות אליה אוטומטית.**
  צריך מיגרציה חד-פעמית שממירה את הערך הקיים, ובגוגל שיט העמודה נשארת טקסט.
- **`currentLesson`** — כיום מספר חופשי. להפוך לבחירה מתוך רשימת המפגשים של הרמה
  של אותה תלמידה (dropdown, לפי התבנית של שאר הדרופדאונים בקובץ — ראי
  "All dropdowns in index.html are custom-built" בקובץ ה-advisor). התצוגה:
  `'מפגש ' + n + ' — ' + title`.
- **שם התלמידה בלוז** מוסיף כיום `' - שיעור ' + currentLesson`. להחליף ל-`'מפגש'`.

## סדר עבודה מוצע

1. `teaching-toolkit.html` — הנתונים והרמה הרביעית.
2. `practice-sheets.html` — גזירה מאותם נתונים.
3. `index.html` — הרמות, המיגרציה, ו-`currentLesson` כרשימה.
4. באג הסימונים.
5. צילומי מסך במובייל ובדסקטופ לשלושת הקבצים, ואז commit ו-push.

## מה לא נמדד

זמני 45 הדקות הם הערכה מתוכננת, לא מדידה. אחרי שני מפגשים אמיתיים לפי המערך
כדאי לעדכן את `phaseTemplate` בהתאם למה שקרה בפועל.

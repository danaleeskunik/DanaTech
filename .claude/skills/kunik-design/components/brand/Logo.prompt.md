The Kunik mark: three ascending rounded bars, read right-to-left as growth. Use it in every product header and on every printed page.

\`\`\`jsx
<Logo height={24} lockup title="ניהול העסק" subtitle="טק בגובה העיניים · דנה קוניק" />
\`\`\`

Bar 1 is always \`--blue-300\`, bar 2 always \`--blue-400\`; only bar 3 changes — white on navy, navy on light (\`onNavy={false}\`). Never recolour the first two bars, never add a wordmark inside the mark. There is no other logo file in the source.

The line-icon set used throughout Kunik Design — 24x24 viewBox, currentColor stroke, round caps and joins.

\`\`\`jsx
<Icon name="whatsapp" size={16} />
<Icon name="chevron-down" size={20} style={{ color: 'var(--ink-7)' }} />
\`\`\`

Stroke weight varies by icon on purpose (1.6 for the pictorial device icons, 1.8-1.9 for UI, 2.2 for checks and chevrons); pass \`strokeWidth\` only to override. \`whatsapp\` is the one filled glyph. Colour comes from the parent's \`color\`.
